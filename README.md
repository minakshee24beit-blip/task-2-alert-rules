# Task 2 – Website Monitoring Alert Rules

## Project Overview
This project defines five alert rules for monitoring a website and identifying problems that require attention.

## Objective
To create alert rules with clear triggers, monitoring frequencies, actions, and possible false alarms.

## Website
Travel Guide Website

## Five Alert Rules

1. **Website Downtime Alert:** Detects consecutive failed website checks.
2. **Slow Loading Alert:** Identifies when mobile LCP exceeds 4 seconds.
3. **Traffic Drop Alert:** Detects a decrease in sessions of more than 30%.
4. **Technical Error Alert:** Detects excessive HTTP 5xx errors.
5. **Negative Review Alert:** Identifies new 1-star customer reviews.

## Tools and Concepts
- Website monitoring
- Google Analytics
- PageSpeed Insights
- HTTP status codes
- Customer review monitoring

## Conclusion
The five proposed alert rules help monitor website availability, speed, traffic, technical errors, and customer feedback. False alarm checks are included to avoid unnecessary notifications.

**Note:** These are proposed rules and are not necessarily configured as active alerts.
